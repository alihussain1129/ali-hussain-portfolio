# Ali Hussain Portfolio

Full-stack developer portfolio and learning platform built with React, ASP.NET Core, PostgreSQL, and ASP.NET Identity.

## Highlights

- Full-stack portfolio experience
- Admin dashboard for course and content management
- Contact form and project showcase
- Designed for deployment on Azure + Vercel

## Tech stack

- React
- ASP.NET Core
- PostgreSQL
- ASP.NET Identity
- Vite

## Local development

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```powershell
cd backend-api
dotnet restore
dotnet run --project ".\AliHussainPortfolio.Api\AliHussainPortfolio.Api.csproj"
```

## Deployment

The project is set up for Azure App Service + Vercel deployment.
