# Contributing

Thanks for your interest in contributing.

## How to contribute

1. Fork the repository and create your feature branch.
2. Make your changes in a focused, well-documented way.
3. Run the relevant checks or tests.
4. Open a pull request with a clear summary of the change.

## Code style

- Keep changes readable and minimal.
- Follow the existing project structure.
- Add comments only when they improve clarity.

## Questions

Open an issue first if you are planning a larger change or a new feature.
